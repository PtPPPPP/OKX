# P1 策略契约验收记录

日期：2026-10-29。范围：五类 V3 研究候选的十组既有参数，统一研究执行、注册身份和逐根只读观察。
没有调整参数、费用、滑点、止损规则或候选晋升标准，没有重新消费原历史样本外数据。

## 实际完成

- 批量研究与逐根策略共用指标和条件计算；研究执行不再预读全部未来信号。
- 实际策略名、配置和报告身份一致；报告附带实现版本及参数。
- 同一 K 线重复到达时不重复发信号；冲突、乱序、缺失、未确认输入明确失败。
- 保存并恢复历史窗口、episode、挂单与持仓时间；恢复前核对持仓和未完成订单。
- 有持仓但缺少入场状态时停止处理，避免错误判断持仓时长。
- 新增无网络、无 Broker 的只读观察适配器和显式 CSV 验证命令。
- 研究候选在非回测交易引擎中禁止提交订单。

## 离线演示与原版本对照

输入是明确标记的 **1,000 根合成 K 线**，不构成真实行情或收益证据。
示例使用已有 `htf_volume_momentum_12` 参数：

- 批量与逐根只读观察信号一致：59 个 BUY，941 个 HOLD。
- 中途保存、恢复后的信号与不中断运行一致。
- 同一策略完成 95 笔模拟成交。
- 将原归档源码也运行在这份合成输入上，两个版本的逐笔成交、已平仓交易、资金曲线和统计一致；
  比较忽略随机运行/订单 ID，新版报告额外的 `strategy_definition` 单独保留。
- 没有调用交易所下单，也没有更改原报告或重新运行原样本外研究。

证据目录：`artifacts/strategy_contract_p1/`。

- `quality_gate.log`：全量测试和初次质量门日志。
- `final_quality_gate.log`：修复格式后的最终静态检查及安全 smoke。
- `final_contract_tests.log`：最后 24 项策略契约回归。
- `offline_demo/verification.json`：批量、逐根及恢复一致性结果。
- `economic_parity.json`：原归档实现与新版的合成数据对照。
- `evidence_preservation.json`：原研究证据保留检查。
- `change_inventory.json`：本次改动文件清单。当前目录没有 `.git`，不宣称 Git 提交或远端验证。
