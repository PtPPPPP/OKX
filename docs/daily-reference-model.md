# 每日交易参考模型 v2：区分现货与合约期限

状态：已实现行情日报和可复现的规则路径回放；策略有效性、预测概率及账户级收益尚未验证。

## 已确认的需求

- 平台：OKX。
- BTC、ARB：现货和永续。
- INTC：`XINTC-USDT` 现货和 `INTC-USDT-SWAP` 永续。
- QQQ：`XQQQ-USDT` 现货和 `QQQ-USDT-SWAP` 永续。
- 黄金：`XAUT-USDT` 现货和 `XAU-USDT-SWAP` 永续，分别计算，不视为同一产品。
- 现货无固定持有期限，投资逻辑成立就持有；具体逻辑和失效条件尚未登记。
- 合约持仓三天以内，研究基线按最多 72 个自然小时计算，不按美股交易日计数。
- 每天手动运行，查看行情参数及一套待验证基线；用户个人策略随后补充。
- 涨跌概率和预测区间为后续可选研究项，目前留空，不以技术评分代替概率。

2026-10-29 的 OKX 公共目录核对返回上述 10 个产品为 live。
用户确认股票现货使用 x 前缀产品；与无 x 前缀的永续分开，不能将两者的历史相互替代。
每次运行均重新查询目录；公共目录存在不等于用户账户具备交易权限。

## 每天怎么运行

在项目根目录执行：

```powershell
.\scripts\run_daily_reference.ps1
```

或直接调用 Python：

```powershell
.venv\Scripts\python.exe -m scripts.daily_reference --config configs/daily_reference.json
```

无需 API Key。不读取 `.env`，复用进程环境里的 `OKX_NETWORK_MODE` / `OKX_PROXY_URL` 网络配置。
没有后台常驻任务或自动下单。建议每天在同一个时刻运行，以保持历史每日采样时点一致。

输出在 `artifacts/daily-reference/<UTC时间_唯一标识>/`：

- `report.md`：中文日报。
- `report.json`：结构化参数、逐笔回放和数据哈希。
- `config.json`、`instruments.json`：本次模型参数和公共产品元数据。
- 每个产品的 CSV：已收盘、连续、UTC 对齐的 1H K 线。
- 每个产品的 context JSON：实时盘口、资金费率、持仓量快照，附各自时间戳。

返回码：0 表示所有可用产品计算完成，1 表示部分产品错误，2 表示没有可计算产品或运行失败。
目录里不存在的现货显示 `UNAVAILABLE`，与行情请求失败的 `ERROR` 分开。
附加快照缺失或过期显示 `PARTIAL`，不得把缺项当成零。

离线复现一次保存的运行（将路径换为实际目录）：

```powershell
.venv\Scripts\python.exe -m scripts.daily_reference --replay-run artifacts/daily-reference/实际运行目录
```

该命令沿用原配置、截止时间、产品元数据和行情，校验 CSV 哈希，不联网，输出到新的目录。
它复现计算，不把旧报告重新标成当前行情。
若旧快照缺少 `spot_policy`，离线重放保留旧短线研究语义，并显示历史模式。

## 输出参数与基线规则

| 参数 | 明确定义 |
|---|---|
| 4H 趋势 | 完整 4H 的 SMA20/SMA50，且最新完整 4H 收盘位于 SMA50 同侧，否则混合 |
| ATR14 | 最近 14 根 1H 真实波幅的算术均值；不是 Wilder 平滑口径 |
| ATR% | ATR / 当前已收盘价格 × 100 |
| 前 24H 高低点 | 信号 K 线之前的 24 根高低点，排除信号 K 线 |
| 相对成交量 | 信号 K 线基础资产成交量 / 此前 20 根均量 |
| 资金费率 | 当前 API 快照及本次结算周期；不假定所有合约固定 8 小时 |
| 持仓量 | 当前张数、美元名义值；单点不能推断增减趋势 |
| 点差 | 当前买卖中价为分母的 bps；不等于保证可成交成本 |

现货默认 `spot_policy=thesis_hold`，仅输出 `OBSERVE` 和技术观察，不设到期日，
不输出小时级止损/目标或短线回放成绩。`OBSERVE` 不代表长期投资逻辑已验证。
完整政策见 [个人交易规则](personal-trading-policy.md)。

合约研究基线：4H 上行且最新 1H 收盘高于前 24H 高点时记录做多条件；
4H 下行且最新 1H 收盘低于前 24H 低点时仅永续记录做空条件。
止损距离为 1.5 ATR，目标距离为 3 ATR，按当前 tick 对齐，最多持仓 72 小时。
未触发时为 `WAIT`；这些阈值是初始工程基线，没有通过盈利有效性检验。

入场参考使用信号收盘价标注，但历史回放只能在下一根开盘成交，不能以信号收盘即时成交。
计划参考在信号后一小时到期，执行前需重跑；日报不会在盘中盯住止损或更新条件。

实时资金费/持仓量等在 K 线截止之后采集，仅作当前上下文，不回填到历史信号。
XINTC/XQQQ 使用 OKX 代币化股票现货行情，INTC/QQQ 使用股票永续行情，
均不能冒充传统美股交易所的直接行情；XAUT 也不是 XAU 永续的替代历史。
财报、宏观事件、节假日的额外交易环境标签尚未接入。

## 回放的用途与限制

- 当前用于合约；现货 `tactical_research` 模式用于保留旧研究快照的复现口径。
- 用最近最多 90 天历史，每日只在本次报告的 UTC 小时检查一次，单产品不重叠持仓。
- 下一根开盘评估入场；如果开盘越过止损或目标，跳过该次入场。
- 跳空越过止损按更差的开盘价处理；同根同时触及止损和目标，优先按止损。
- 默认单边手续费 10 bps、滑点 5 bps，来自配置假设，并非用户账户实际费率。
- 每笔按入场名义价值计算，统计均值；没有组合收益、收益承诺或模型胜率预测。
- 未模拟资金费、保证金、强平、最小下单量、成交量约束、市场冲击和组合资金占用。
- 未结束交易单独计数，不假装已平仓。
- 这是价格路径诊断，不是完整账户回测，也不是样本外成绩；不可据此评价合约净收益。

后续验证要先冻结规则与成本假设，再进行时间顺序的训练/验证/测试切分和前向记录；
若加入 24/48/72 小时预测，训练标签必须在当时已完整落地，切分边界要隔离重叠标签，
并报告相对于简单基线的效果、概率校准及价格区间覆盖率。数据不足时继续留空。
